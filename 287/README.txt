Ravedio 287 | Longer soft brow fringe

The owner-preferred source for this hairstyle is 281 A, Soft brow fringe.
This longer cut uses the original fringe positions and material. The new
side and back panels fall gradually through the nape into a shallow curved
hem. The broader layered relief and finer strands follow the same flow.
The revision is for bare-head review. Headwear and production color fits
are pending.

Reproduce
With the local 270 asset cache available, run Blender 5.2 in background mode
with --python 287/tools/build_fringe.py. Serve the artwork root and run
287/tools/capture.cjs with Playwright and Chromium to regenerate the views.
Use --baseline to capture the matching rear views of 281 A.
