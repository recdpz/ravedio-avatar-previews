Ravedio 289 | Rounded and layered cuts

Both studies start from the shared 287 shape and 281 Soft brow fringe.
A curves the lower profile inward like a rounded blowout and uses 11
evenly spaced, softly rounded fringe pieces. B uses broader waves that
fall behind the shoulders, a graduated rear hem, and 13 finer pieces.
The fringe spacing is laid out across the face in front projection.
The three looks use the same camera, palette and lighting. Headwear
fits and production color variants are pending.

Reproduce
With the local 270 asset cache available, run Blender 5.2 in background
mode with --python 289/tools/build_cuts.py. Serve the artwork root and
run 289/tools/capture.cjs with Playwright and Chromium. Run it again
with --layered for the second cut.
