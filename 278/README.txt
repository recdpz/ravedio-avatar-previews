Ravedio 278 | Rolled wispy fringe

Thirty-two fine wisps share a rounded roll in profile. The main sweep
lifts outward and turns back close to the forehead. Small variations
in strand width, spacing and end height keep the fringe airy. The front
crown tapers gradually into an irregular edge with recessed strand roots.
The cap, beanie, bucket and cowboy hat use shallower covered fits.

The wisps export together as one mesh with the existing selectable hair.
The Space Buns entries point to the exact 276 assets.

Review
Eight-angle browser checks covered both hairstyles with
all headwear choices, with additional Ombre and 120-pixel portrait views.
The geometry checks confirm that the two color versions match and that
the pashmina clears the hair on all eight tops. The bare-fringe export
check measures the crest, inward return and tip clearance on all 32 strands.

Reproduce
Prepare the 270 generated cache and 274 and 276 assets. Run Blender 5.2
in background mode with --python 278/tools/roll_fringe.py. Run
275/tools/verify_assets.py -- 278 and 278/tools/verify_roll.py with
Blender. Run 275/tools/review.cjs with REVIEW_REVISION=278 and
CAPTURE_DIR set while the local artwork server is available.
