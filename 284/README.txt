Ravedio 284 | Side-brushed fringe

The fringe crosses the brow in a diagonal curve with a shallow break
near the longer end. Swept surface ridges define the layers. The front
edge curves away from the head and returns close to the forehead.
The comparison uses the same camera, lighting, clothing and color as 283.
This is a bare-head study. Headwear fits and color variants are pending.

Reproduce
With the local 270 asset cache available, run Blender 5.2 in background mode
with --python 284/tools/build_fringe.py. Serve the artwork root and run
284/tools/capture.cjs with Playwright and Chromium to regenerate the views.
