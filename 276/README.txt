Ravedio 276 | Softer fringe and defined back waves

Wispy Bangs now grows out of the crown as one continuous sculpted surface.
Individual locks curve sideways and end at staggered lengths with softly
rounded tips. The gaps keep the fringe airy above the eyes.

Space Buns adds seven gently offset wave sections below the crown. Their
soft valleys carry through the lower outline. The new volume stays
behind the shoulders. The bun placement and triangular bandana use the
existing fit. The pashmina keeps the loose lengths tucked in.

Review
Both styles were inspected with no headwear and all seven headwear choices.
The browser receipt covers eight angles in Default, two in Ombre, mobile
selection and a 120-pixel portrait with clear reading glasses. The GLB
checks compare color geometry, verify the protected bun crown and confirm
clearance across the eight pashmina top variants.

Reproduce
Prepare the 270 generated cache and 274 bandana assets. From the artwork
root, run Blender 5.2 in background mode with --python
276/tools/refine_hair.py. Run Blender with --python
275/tools/verify_assets.py -- 276 to verify the exports. Run the
275/tools/review.cjs Playwright script with REVIEW_REVISION=276 and
CAPTURE_DIR set while the local artwork server is available.
