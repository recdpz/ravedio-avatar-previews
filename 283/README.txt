Ravedio 283 | Soft brow fringe refinement

This bare-head study follows 281 A. Uneven openings break up the fringe,
and the grooves run into those openings. The fringe has a shallow outward
curve before the tips settle close to the forehead. The sides blend into
the brow and end in a softer hem. The two previews share camera, lighting,
clothing and color. Headwear fits and production color variants are pending.

Reproduce
With the local 270 asset cache available, run Blender 5.2 in background mode
with --python 283/tools/build_fringe.py. Serve the artwork root and run
283/tools/capture.cjs with Playwright and Chromium to regenerate the views.
