Ravedio 308 | Women's Jersey

The top of the feminine button-front jersey opens into a modest,
rounded V. The binding sits nearer the chest. One unfastened button
is visible on the side. The closed placket, floating sleeves, cuffs,
waist hem and original body shape are carried through.

The front wordmark is set across the two panels below the opening.
The back wordmark and existing wave artwork were redrawn for a 2048
pixel atlas, including all nine existing colors. The original color
is embedded in the GLB. The preview binds the alternate atlases to
the same material slot. This is an artwork review export.

Review covers the eight camera angles, all nine colors, and
combinations with Twin Braids, Box Braids and Curls. The three tested
pashmina fits clear the updated jersey. The fitted top preserves
the sleeve, cuff and hem geometry. See verification/fit.json.

Rebuild with the 213 feminine jersey source scene, the original 163
jersey pattern and the existing 213 color patterns available. Run
print_art.py with the art repo root, output assets directory, 163
pattern path, and font directory containing Impact and Arial. Open
the 213 jersey scene in Blender background mode and run fit_jersey.py
with the default atlas, GLB destination, and .blend destination after --.
Run review.cjs with CAPTURE_DIR to capture 307 and 308 at matched
angles, then run verify.py in Blender with the review.json receipt.
