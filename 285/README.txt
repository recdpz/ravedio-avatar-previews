Ravedio 285 | Soft bangs

The fringe falls across the forehead in a shallow curve with longer
corners. Short separations between groups of tips soften the edge.
The shell follows the forehead and the ends roll in toward it.
The comparison uses the same camera, lighting, clothing and color as 283.
This is a bare-head study. Headwear fits and color variants are pending.

Styling reference
ONIS Hair Salon, Layered Shag with Wispy Bangs
https://www.kiri-me.com/style/layered-shag-with-wispy-bangs

Reproduce
With the local 270 asset cache available, run Blender 5.2 in background mode
with --python 285/tools/build_fringe.py. Serve the artwork root and run
285/tools/capture.cjs with Playwright and Chromium to regenerate the views.
