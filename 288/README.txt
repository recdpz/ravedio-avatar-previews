Ravedio 288 | Hair depth and fringe spacing

281 A is the owner-preferred Soft brow fringe. Both options here build
on revision 287. A has a rounder shape through the lower hair and a few
recessed ends beneath the hem. B uses the same lower geometry and varies
the spacing and depth of the existing six gaps, with comparable brow
coverage. Both use the same camera, palette, material and lighting as 287.
Headwear fits and production color variants are pending.

Reproduce
With the local 270 asset cache available, run Blender 5.2 in background
mode with --python 288/tools/build_layers.py. Serve the artwork root and
run 288/tools/capture.cjs with Playwright and Chromium. Run capture.cjs
again with --spacing for the second fringe option.
