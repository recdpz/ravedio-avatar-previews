Ravedio 280 | Wispy bangs with a shallow part

Seven uneven fringe sections follow the crown and split near their ends
into twenty finer tips. A shallow off-center part sets the direction on
each side. The temples taper into the longer sides. The roll turns back
toward the forehead earlier, with small differences in the length and
spacing of the rounded ends. Closed hats use a shallower fit.

Review
The bare sculpt was compared with 279 before preparing the covered fits.
The next passes removed a fold at the left temple and softened the tips.
The browser review covered eight angles with every headwear selection,
both Default and Ombré, and a 120-pixel portrait with clear glasses.
The GLB checks verified matching geometry across the color variants and
pashmina clearance across all eight tops. Space Buns uses the 276 assets.

Reproduce
Prepare the 270 generated cache and 274 and 276 assets. Run Blender 5.2
in background mode with --python 280/tools/parted_fringe.py. Run
275/tools/verify_assets.py -- 280 in Blender. Run 275/tools/review.cjs
with REVIEW_REVISION=280 and CAPTURE_DIR set while the local artwork
server is available.
