Ravedio 306 | Box Braids

The front braids frame the face with a smoother shoulder curve. The
side lengths lift around the sleeves, and the back falls in staggered
layers. The original woven geometry narrows toward the ends, with
shorter tips below the bands. On the uncovered style, the roots sit
closer to the crown and make a narrower center part.

The pashmina fit keeps the lower front exit from 304. Shorter rear
layers reduce the row of bands beneath the scarf. The existing
headwear root fits receive the same lower shaping where appropriate.
Original Brown and Ombré retain their authored materials and maps.

The selector check covers 104 combinations, with changes limited to
the hair component in 44 Box Braids combinations. Ten ordinary GLBs
preserve the original topology and material data. The lower braid
check measures intersections below Y=1.50 against the selected body,
top and headwear. Upper braid contacts at the scalp are outside that
check. See verification/fit.json for counts and hashes.

Rebuild with revision 305 and its generated assets available. Serve
the preview root and set ART_REVISION=305. Run
node 305/tools/resolve.cjs before.json. Run Blender in background mode
with 306/tools/sculpt.py, passing before.json after --. Set
ART_REVISION=306 and run the resolver to produce after.json. Run
Blender with 306/tools/verify.py, passing both receipts after --.
For matching captures, run node 306/tools/review.cjs with CAPTURE_DIR.
Set REVIEW_HEADWEAR=1 for all headwear and 120 px portraits. Local
generated GLBs are in 306/assets.
