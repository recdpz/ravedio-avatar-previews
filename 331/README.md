# Bob end treatments

Three directions for the ends of the feminine Bob, based on the packed
revision 330 studio model.

- Feathered thins and bevels the ends along the existing wave and adds
  shallow channels in the face of the locks.
- Flipped curves the lower layers inward before turning the tips out and up.
- Tucked draws the ends closer to the jaw and settles the lower edge into
  a more even silhouette.

These are hair review scenes with the bare Bob and the same studio
framing. The catalogue stays on revision 330 while the treatments are
under review. Headwear fits and other hair colors are outside this review.

Render the scenes in Blender 5.2.0 by running
`tools/bob_directions.py` with the packed revision 330 Bob scene and an
output directory after `--`. Mount the output directory at `331/files`
for the gallery, angle renders and editable Blender scenes. Run
`tools/make_comparison.py OUTPUT` with Pillow to assemble the comparison.
